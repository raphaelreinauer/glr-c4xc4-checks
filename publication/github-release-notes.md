# Version 1.0.0

Six exact-arithmetic verification scripts accompanying Appendix A of
*The Gromov–Lawson–Rosenberg Conjecture for the group Z/4 x Z/4*.

- Eta fixed-point sums, actual target periods, Smith forms, and a symbolic
  universal 2-local diagonalization certificate.
- Primitive complex symmetry and real E3/third-differential rank checks.
- Exact rational identities and mixed spin-index/Gysin calculations.
- Pinned dependencies, a runner with assertion safeguards, verification
  output, and source provenance.

These scripts supplement the written proofs. Finite-range tests are not
claimed to establish all-degree theorems; see the README for their scope.
